# DEVELOP: StS2 形态(Form)Mod 规格契约

状态: 规格已定稿, P0 反编译研究待补 (Locke 未落盘, 需重派 scout)
最后更新: 2026-09-26  作者: 主会话(Kiro)  用户已逐条确认

## 概念
基于观者(Watcher)姿态系统做"形态"mod. 复用四姿态的进入方式, 但把内容换成 6 个形态,
按姿态分组、每姿态同时挂载两个形态的效果. 无姿态 -> 无形态(不改, 不走易出问题的实现路径).

## 姿态 -> 形态映射 (每姿态同时生效两形态)
| 原姿态 | 形态A | 形态B |
|---|---|---|
| 平静 Calm | 虚空形态 | 群蛇形态 |
| 愤怒 Wrath | 恶魔形态 | 死神形态 |
| 神格 Divinity | 回响形态 | 天人形态 |
| 无 None | (无形态, 不改) | - |

## 六形态效果 (n = 当前回合数)
1. 虚空形态: 本回合下 1 张牌免费打出; 之后每回合开始时若处在此姿态, 该回合第一张牌免费打出.
2. 群蛇形态: 每次出牌对随机敌人造成 3 伤害; 离开该姿态时获得 2 能量.
3. 恶魔形态: 获得 =(1+2+...+n) 力量; 从所有敌人处受到的每次伤害 +n.
   - n 随回合刷新(每回合按当时回合数重算力量与受伤加成).
   - 力量与"受伤+n"均随退出该姿态而消失(需追踪本姿态施加量并在退出时回滚).
4. 死神形态: 复用原版死神(ReaperForm)效果 = 每次出牌造成伤害时给敌人等量灾厄(DoomPower).
   - 触发判据见 MECH-reaperform-doom-20260926.md (IsPoweredAttack + dealer∈{玩家,宠物}).
5. 回响形态: 下一张牌多打出一次.
6. 天人形态: 立刻获得 =max{n,3} 能量并抽 max{n,3} 张牌; 下回合开始时自动退出该姿态.

## 全局规则
- 姿态不可叠加; 切换姿态时自动退出当前姿态(触发退出效果, 如群蛇+2能量、恶魔回滚力量/受伤).
- 保留观者原有的姿态切换联动(Rushdown/Mental Fortress 等"切换姿态时触发"类).

## 待澄清/默认 (P0 研究后确认)
- 恶魔"受伤+n"的实现 hook (atDamageReceive 类) 与回滚机制.
- 群蛇"随机敌人"选取的 RNG counter (须用 CombatTargets/Niche 之类确定性 RNG, 避免多人分歧).
- 天人/虚空免费打牌复用的 free-to-play 字段.
- 各形态是否需要各自的 Power 承载状态.

## 多人分歧警戒 (来自 sts2-divergence-analysis-r1)
本工作区已知多人状态分歧两类根因: 卡身份(SPIRE1- 前缀不一致) 与 CombatCardGeneration RNG 错位.
新形态若引入随机(群蛇随机敌人)或卡生成, 必须走确定性 RNG counter, 否则会制造新的多人 checksum 分歧.
