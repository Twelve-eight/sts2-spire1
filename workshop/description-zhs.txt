[h1]Spire1:一代三角色[/h1]

将初代杀戮尖塔的三名角色 - 铁甲战士 / 静默猎手 / 故障机器人 - 完整移植到杀戮尖塔 2.

[hr]

[h2]内容[/h2]

[list]
[*][b]3 名可玩角色[/b]:铁甲战士(Ironclad)/ 静默猎手(Silent)/ 故障机器人(Defect),各自的角色机制(怒气 / 毒素 / 充能)原样还原
[*][b]233 张卡牌[/b]:一代卡池完整移植(基础牌 / 普通 / 罕见 / 稀有 / 状态 / 诅咒)
[*][b]28 件专属遗物[/b]:燃血 / 蛇之戒指 / 破裂核心等角色核心遗物,数值按二代引擎语义适配
[*][b]53 个一代事件[/b]:全部 "? " 房事件(含各区域专属事件与神龛类共享事件),按原作区域对应投放进二代的四个大区
[*][b]3 种药水[/b]
[*][b]完整简体中文本地化[/b]:卡牌 / 遗物 / 事件描述均支持动态数值
[/list]

[h2]卡池说明[/h2]

一代角色的卡牌加入各自角色的卡池(选择对应角色时出现),并按规则进入无色/事件奖励等通用池.与二代原生内容并存,不替换任何二代卡牌.
